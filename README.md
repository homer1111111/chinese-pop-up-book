# Chinese Pop-up Book

A 3D pop-up picture book for the Jinan University *Zhongwen* (《中文》) textbook series, Books 1–5.

**Live site:** https://homer1111111.github.io/chinese-pop-up-book/

## Features
- A school campus with one building per volume; each classroom has a bookshelf of 12 lessons
- Hand-built 3D scenes for every lesson, page by page, following the lesson text
- Speech bubbles for every sentence of the text; extra lines are spoken by the little owl and marked as supplementary
- Pinyin / Zhuyin annotation, read-aloud with adjustable speed, follow-along reading
- Character cards, flip cards, quizzes and ten mini-games (four in 3D)

## Files
- `index.html` — the whole app in a single file (three.js and GSAP load from a CDN, so an internet connection is needed)

## Updating
Replace `index.html` with the new version. If the phone still shows the old one, open the link with `?v=2` (or any new number) at the end.
